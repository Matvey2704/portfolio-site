# Portfolio Site

Личный сайт-портфолио frontend разработчика.

## О проекте

Сайт с реальными кейсами из продуктовой разработки: работа с API, обработка ошибок, стабильный UI и доведение фич до рабочего состояния.

## Стек

- React
- TypeScript
- Vite
- SCSS

## Проекты

### 1. Форма отзывов с API
Реализация формы с отправкой данных, обработкой ошибок и обновлением UI после создания.

Demo: https://react-review-form-theta.vercel.app  
Code: https://github.com/Matvey2704/react-review-form  

---

### 2. Профиль / Dashboard
Интерфейс с подключением API, состояниями загрузки, пустых данных и ошибок.

Demo: https://react-profile-dashboard-psi.vercel.app  
Code: https://github.com/Matvey2704/react-profile-dashboard  

---

### 3. Дебаг и стабилизация API
Интерактивная панель для анализа API-запросов: фильтрация по статусам, просмотр payload и обработка ошибок.

Demo: https://react-api-debug-panel.vercel.app  
Code: https://github.com/Matvey2704/react-api-debug-panel  

---
